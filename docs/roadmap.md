# Roadmap

## Phase 1 — Foundation
Workspace, dashboard, PostgreSQL/Drizzle, core models, and project/memory CRUD.

## Phase 2 — Useful memory
Memory UI, hybrid search, project context, and richer task management.

## Phase 3 — AI
Provider implementations, cited chat, automatic extraction, and deduplication.

## Phase 4 — GitHub
OAuth, repository import, commits, issues, pull requests, and activity timeline.

## Phase 5 — Daily brief
Summaries of activity, tasks, decisions, risks, and a suggested next step.

Multi-agent orchestration, autonomous coding, teams, mobile apps, and full AST analysis are explicitly outside V1.
